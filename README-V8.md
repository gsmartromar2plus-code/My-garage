# MY GARAGE v8.0 — development build

Це окрема гілка розробки на базі наданого архіву v7.1 / вмісту main. Існуючий інтерфейс та JSON-модель v7 залишено як основу; дані автомобілів не конвертуються у вигадану нову структуру.

## Що закладено у v8

- Cloudflare Worker API замість Netlify Functions.
- D1: користувачі, сесії, одноразові email-посилання, гаражі, історія ревізій та блог.
- R2: окреме сховище медіа.
- Вхід Google OAuth та вхід за одноразовим посиланням на email (Resend).
- Гараж і вкладення ізолюються за серверною сесією; `user_id` з браузера не приймається як джерело авторизації.
- Оптимістичне керування ревізіями гаража.
- Для кожного допису блогу окремий `public` / `private` режим. Приватний допис і його медіа доступні лише автору; перевірка виконується сервером.

## Важливо про стан інтеграції

Це **development build**, а не готовий production-реліз. Екран входу (Google/email), перевірка сесії, вихід, сторінка блогу, створення/редагування/видалення дописів і перемикач видимості вже інтегровані. Вкладення блогу завантажуються у R2, а доступ до медіа перевіряється через ID допису та його visibility. Залишилися перевірки у справжньому Cloudflare середовищі, налаштування OAuth/email та повний сценарій тестування з кількома обліковими записами.

## Підготовка Cloudflare

1. Створити окремі D1 database та R2 bucket саме для v8. Не підключати production v7 базу.
2. Внести D1 `database_id` у `wrangler.toml`.
3. Встановити секрети через Wrangler: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `RESEND_API_KEY`.
4. У Google Cloud Console додати redirect URI `https://ВАШ-ДОМЕН/api/auth/google/callback`.
5. Перевірити домен-відправник у Resend та задати `EMAIL_FROM`.
6. Задати `APP_ORIGIN` точним origin застосунку.

Команди для секретів: `npx wrangler secret put GOOGLE_CLIENT_ID`, `npx wrangler secret put GOOGLE_CLIENT_SECRET`, `npx wrangler secret put RESEND_API_KEY`.
7. `npx wrangler d1 migrations apply my-garage-v8 --remote`.
8. `npx wrangler deploy`.

Локально: `npm install`, `npx wrangler dev`.

## Перенесення v7

Не імпортувати старі записи в D1 автоматично і не запускати міграцію на бойових даних. Імпорт JSON v6/v7/v8 виконується через наявну форму резервних копій: перевіряється структура, користувач бачить кількість авто й записів, підтверджує заміну, після чого завантажується backup поточних даних і виконується збереження в особистий гараж. Для першого входу локальні записи переносяться лише після окремого підтвердження користувача.

## Перевірки

У цій збірці не виконано реальне розгортання Cloudflare, OAuth, доставку email, D1/R2 round-trip або перевірку на iPhone. Не вводьте production secrets у репозиторій. `wrangler.toml` містить навмисні плейсхолдери.
