# MY GARAGE v8.0 — development build

Україномовний автомобільний журнал, розвинений безпосередньо з наданої робочої версії v7. Збережено існуючу модель автомобілів та історії; нова архітектура v8 переходить на Cloudflare Workers + D1 + R2 та додає облікові записи.

## Основні можливості v8

- Вхід через Google або одноразове посилання на email.
- Особистий гараж користувача з синхронізацією між пристроями.
- Серверна ізоляція даних за обліковим записом і контроль ревізій.
- Окреме сховище фото/PDF у R2.
- Блог із незалежним перемикачем «Публічний / Приватний» для кожного допису. Сервер перевіряє доступ як до тексту, так і до вкладених медіафайлів.
- Збережено v7 UI, автомобілі, регламенти, записи, заправки, документи, бюджети, журнал поломок, аналітику, теми та JSON-резервні копії як основу для подальшої інтеграції.

## Стек

- `public/` — статичний PWA інтерфейс.
- `worker/index.ts` — Cloudflare Worker API.
- `migrations/` — D1 SQL migrations.
- R2 — фото та PDF.
- `wrangler.toml` — окремі ресурси v8.

## Запуск і налаштування

Детальна інструкція — у [README-V8.md](README-V8.md). Потрібні Cloudflare D1, R2, Google OAuth client та Resend API key. Плейсхолдери у `wrangler.toml` треба замінити власними значеннями; секрети задаються через `wrangler secret put`, а не комітяться у Git.

Локально: `npm install`, `npx wrangler d1 migrations apply my-garage-v8 --local`, `npx wrangler dev`.

## Важливо

Це проміжна версія `8.0.0-dev.1`, не production-реліз. Потрібні налаштування Cloudflare та зовнішніх OAuth/email сервісів. Перенесення особистих даних v7 не запускається автоматично: перед ним потрібен JSON backup і підтвердження користувача. Файли Netlify залишено у проєкті як історичну/міграційну основу, але v8 їх не використовує.
