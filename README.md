# MY GARAGE v7.1

Україномовний автомобільний журнал, розвинений із наданого MyGarage v6. Збережено наявні регламенти, історію, калькулятор ГБО, декодування VIN, розширене налаштування оформлення: 10 повних тем і персоналізація інтерфейсу та формат JSON.

Інтерфейс має темну панель автопарку, п’ять мобільних вкладок, профілі автомобілів, обслуговування, заправки, аналітику, календар, документи з фото/PDF, журнал поломок, бюджети, вартість володіння, пошук і друк звітів у PDF засобами браузера.

## Технології та запуск

Статичні HTML/CSS/JavaScript без збірки фронтенду; Netlify Functions на TypeScript; Netlify Database із Drizzle ORM; Netlify Blobs для вкладень; manifest і Service Worker для PWA.

Потрібні Node.js 22+, Netlify CLI і прив’язка до Netlify-проєкту. Встановіть пакети командою `npm install`, потім запустіть `netlify dev --port 8889`. Відкрийте http://localhost:8889. Статична папка публікації — `public`; функції — `netlify/functions`. Схему описано у `db/schema.ts`; міграції платформа застосовує під час розгортання.

## Перенесення даних

Архів v6 містив код, а не особисті записи. Збережені на іншому домені/пристрої дані потрібно експортувати з v6 в JSON та імпортувати у «Резервні копії». На тому самому домені наявний ключ `mygarage` або старий `mtb` читається для початкового перенесення, але не перезаписується. Всі нові записи зберігаються у Netlify Database. Фото/PDF зберігаються у Blobs, а експорт знову включає файли у JSON. Імпорт спочатку перевіряє структуру та завантажує копію поточних даних перед заміною.

Хмарний гараж прив’язано до HttpOnly cookie браузера. Це не обліковий запис і не синхронізація між пристроями. Очищення cookie створює новий гараж; регулярно завантажуйте JSON. Конфлікт із іншою вкладкою блокує перезапис. Під час помилки збереження експортуйте поточні зміни та не закривайте сторінку. Офлайн кешується оболонка, але запис даних вимагає мережі.

## Межі випуску

Нагадування працюють у застосунку, без системних push. PDF створюється через діалог друку браузера. Вартість володіння залежить від повноти внесених витрат. Журнал поломок не дублює витрат: ремонт треба додати до історії обслуговування. Статичний Netlify Drop сам по собі не розгортає функції та базу: повна версія використовує стандартне розгортання Netlify з репозиторію.

Під час цієї сесії команди збірки, запуску й тестів не виконувалися. До підтвердження випуску необхідні автоматична перевірка платформи, перевірка на реальному iPhone Safari/PWA і імпорт особистої резервної копії користувача. В архіві v6 не було тестових особистих даних.


## Оновлення v7.1

Повністю оновлено візуальну систему: адаптивна композиція, перероблені картки, навігація та налаштування. Додано 10 стилів (Midnight, Ocean, Graphite, Forest, Ember, Violet, Sand, Arctic, Racing, Luxury), миттєвий вибір теми, акцентні кольори, геометрію, фон, щільність, масштаб тексту, компонування, стиль навігації, вигляд карток автомобілів та керування анімаціями. Налаштування зберігаються локально та включаються до JSON-резервної копії. Дані автомобілів і бізнес-логіка v7 збережені.
